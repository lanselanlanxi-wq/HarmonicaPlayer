# HarmonicaPlayer 0.1.5

Windows 10/11 x64 口琴简谱自动演奏工具。支持 UTF-8 TXT 导入、节奏解析、音符时间列表预览，以及自定义开始/停止快捷键。

[下载程序](https://github.com/lanselanlanxi-wq/HarmonicaPlayer/releases/latest) · [源码](https://github.com/lanselanlanxi-wq/HarmonicaPlayer)

## 使用方法与常见问题

发布包内的 `使用说明.txt` 只包含使用方法和常见问题，以下同步提供完整内容。

一、开始使用

1. 解压全部文件。按目前的游戏使用建议，右键 HarmonicaPlayer.exe，选择“以管理员身份运行”；游戏建议使用无边框窗口模式。
2. 在游戏中装备并进入口琴演奏状态，站在稳定位置，关闭聊天框、背包和其他菜单。
3. 导入UTF-8编码的TXT简谱。TXT只放谱面，不要包含标题、歌词、页码或说明文字。
4. 如果谱子包含长短音、休止符等节奏标记，勾选“节奏模式”，设置BPM。
5. 可以先勾选“仅日志测试”，检查解析预览及播放进度。准备实际演奏时必须取消勾选。
6. 默认F6开始、F8停止，也可在“自定义快捷键”中修改。
7. 开始前不再弹出确认窗口。松开开始快捷键及修饰键后直接倒计时3秒；若在程序中点击开始，请在倒计时内切回游戏。保持游戏口琴界面在前台。
8. 演奏期间除按停止快捷键外，请勿触碰鼠标键盘。切换窗口会自动停止。再次开始会从头演奏。

二、两个模式是什么意思

【仅日志测试】
勾选：只显示演奏进度和日志，不发送键鼠输入，也不发声，游戏里不会自动弹奏。
取消：发送实际演奏输入。
每次启动程序都会默认勾选，需要实际演奏时请手动取消。

【节奏模式】
勾选：识别长短音和休止符，按BPM演奏。空格、换行只用于排版，不额外停顿。
例如5_是半拍，5__是四分之一拍，5.是1.5拍，5 —是两拍，0是休止一拍。
不勾选：使用每音固定时长，并按设置添加空格、换行停顿，适合只有音符数字的旧式文本谱；不能识别_、附点和延长符。
该选项与“仅日志测试”互相独立：既可以测试节奏谱，也可以实际演奏节奏谱。

三、常见问题

1. 有日志但游戏不弹、没有声音？
先检查是否仍勾选“仅日志测试”。实际演奏要取消它，并保持游戏口琴界面在前台。
若仍无输入，关闭程序后以管理员身份重新启动，确认游戏已进入口琴演奏状态。管理员身份不保证所有场景都能响应输入。

2. 提示无法识别“_”“.”或“—”？
先勾选“节奏模式”。若仍报错，检查是否混入标题、歌词、星号或其他不支持的符号。

3. 曲子太快或太慢？
节奏模式下调BPM：数值越低越慢，越高越快。没有标速度的谱子需要自己调整。
固定时长模式下调“旧模式每音(ms)”：数值越大越慢。

4. 音之间太断，或每句停顿太久？
留白控制每个音结束前提前松开的时间，可先试10～20ms。
句尾停顿通常来自谱子里的0；BPM降低时休止也会变长。节奏模式的空格/换行停顿设置不生效。

5. 快捷键被占用或停止键不可用？
先关闭旧版本及重复运行的程序，再修改快捷键或点“重试注册”。
开始键不可用时仍可点开始按钮；停止键不可用时禁止真实演奏。

6. 为什么演奏时不要动鼠标键盘？
程序会用键盘和鼠标组合发出不同音区的音符，手动操作可能干扰演奏或改变游戏状态。需要操作时先按停止键。
建议使用无边框窗口模式；这只是使用建议，不代表能解决所有输入问题。

7. 站在长弓溪谷的船上，被其他人带走后按键没反应？
已有该场景的用户测试反馈，原因待确认，本版尚未针对它修复。
请先停止自动演奏，可尝试上岸、重新进入口琴演奏状态，再开始；必要时重启播放器。这些是排查步骤，不保证一定恢复。
目前建议避免在移动船只上自动演奏。

8. 谱子里有双高音或双低音？
程序只支持低、中、高三个音区，不能直接输入双高音、双低音或嵌套括号。需要先调整八度，再导入；具体AI转换提示词见README。

9. 关闭较慢怎么办？
0.1.4起已优化关闭流程。关闭时需要先停止演奏、释放按键并保存设置。
若提示按键释放失败，按提示手动按下并松开相关键，再尝试关闭。仍有异常请反馈版本、当时是否演奏及提示截图。

10. 程序能直接识别图片或MIDI吗？
不能。图片需要先转换成程序格式的TXT；程序的预览是音符时间列表，不是声音试听。

## 0.1.5 更新

- 移除实际演奏前的确认弹窗；游戏内使用快捷键可直接进入倒计时，相关提示移至主界面。
- 保留每次启动默认“仅日志测试”、停止热键检查和失焦停止。
- 同步更新使用说明与README，补充模式说明、输入排查和AI转谱时的八度处理。
- 发布脚本自动将使用说明.txt放入Windows发布包。

## 0.1.4 关闭与响应优化

- 修正关闭事件中再次关闭窗口的重入风险，统一先退出本次关闭事件，再停止任务和关闭窗口。
- 点击关闭先取消演奏，等待任务退出后再释放输入；关闭清理改为异步，避免在界面线程等待原生输入清理。
- 设置改为后台顺序写入，重复快照不重复写盘，最后修改不会被旧写入覆盖。
- 关闭时停止预览和日志刷新，编辑谱子的预览增加短延迟合并，减少密集刷新。
- 如果系统输入清理或保存较慢，显示等待状态并保持界面消息处理；不会在演奏线程仍运行时强制结束进程。
- 按键释放失败时保留窗口和提示，手动松开相关键后可再次关闭。

## 0.1.3 快捷键与设置

- 点击“自定义快捷键”，点击录入框直接按键，也可使用下拉框和 Ctrl / Alt / Shift 勾选项。
- 默认 F6 / F8；支持组合键，例如 Ctrl+F6、Ctrl+Shift+F8。
- 开始和停止不能相同。F12、Win组合和部分系统组合不可用；Z/X/C/V/B/N/M/逗号保留给音符输出，包括以这些键组成的组合键。
- 字母、数字、空格需配合修饰键，减少全局快捷键对输入的影响。
- 应用后在主界面分别显示注册结果；若占用，重新修改或解除冲突后点“重试注册”，不用重启。
- 开始键注册失败时可点按钮开始；停止键注册失败时禁止真实输出，仍可运行仅日志模式。
- 编辑快捷键期间不演奏，临时释放全局快捷键；取消编辑会重新注册原设置。
- 启动前等用户松开启动键和修饰键；倒计时结束也会再次检查，等待超过15秒取消。
- 自动保存快捷键、节奏模式、BPM、留白及分段停顿。每次启动仍默认“仅日志测试”。
- 设置保存在 `%LOCALAPPDATA%\HarmonicaPlayer\settings.json`，不在发布包内。无效/损坏设置会回退默认值并提示。
- 0.1.3及以后同一Windows用户会话只运行一个实例；再次启动尝试恢复并激活已有窗口。旧版0.1.2不具备该机制，升级前请关闭旧版。

## 简谱格式

TXT仅放音符，不包含标题、歌词、BPM或拍号声明。AI转换图片后仍需核对高低音点和节奏标记。

| 文本 | 含义 |
| --- | --- |
| 1～7 | 中音，一拍 |
| 【123】 | 高音 |
| （123）或 (123) | 低音 |
| #6 | 下一个音升半音 |
| 5 — 或 5 - | 两拍，持续同一个音 |
| 5_ / 5__ | 半拍 / 四分之一拍 |
| 5. / 5_. | 1.5拍 / 0.75拍 |
| 0 / 0_ / 0 — | 休止1拍 / 半拍 / 两拍 |
| \| | 小节分隔，本身不加停顿 |

节奏模式中空格/换行只用于排版，停顿写0。旧模式继续使用每音固定毫秒数和空格/换行额外停顿。
留白包含在音符的总时长中，不会增加总时长；最短非休止音扣除留白后至少40ms。留白范围10～5000ms。
预览是音符时间列表；本版不提供声音试听、图片识谱、标准简谱图形排版、MIDI、连音线、三连音或小节拍数校验。

现有游戏输出映射：普通1～7使用Z/X/C/V/B/N/M；高1使用逗号；高2～7配合鼠标右键；低音配合左键；升半音配合中键。0.1.3自定义的是开始/停止快捷键，并非这些演奏映射。

## 给其他AI的转谱提示词

将乐谱图片与下面的提示词一起发给AI。转换后仍需核对音符和节奏；“每小节拍数一致”不代表识别绝对准确。

```text
请把这张简谱转换为 HarmonicaPlayer 节奏模式可导入的纯文本，规则如下：

- 中音：1～7；高音：【1】；低音：（1）。
- 升半音：#1。若有降号，请转换为音高相同且程序支持的写法，并在谱子外说明，无法确定时不要猜测。
- 普通音符占一拍，以四分音符为一拍。
- 延长一拍：在音符后加“—”，例如“5 —”共两拍。
- 半拍：5_；四分之一拍：5__。
- 附点：5.为1.5拍，5_.为0.75拍。
- 休止符：0为一拍，0_为半拍，0 —为两拍。
- 用空格分隔音符，用 | 分隔小节，每行一个小节。空格和换行不增加停顿。
- 高低音与时值可以组合，例如【5_】、（3.）。

请准确识别音符上下的高低音点、下方减时线、右侧附点和休止符，并核对每小节总拍数；弱起小节等不足整小节的情况按原谱保留，不要为了凑拍擅自加休止。

【超出音域的处理】
程序只支持低、中、高三个音区，不能直接表示升两个八度或降两个八度，也不能使用嵌套括号。
遇到双高音（上方两个点），允许降一个八度，改为普通高音；例如双高音1写为【1】，而不是【【1】】或**1。双低音同理可升一个八度，改为普通低音。
请优先检查能否将整首曲子统一降低或升高一个八度，使全部音符落在支持范围内，以保留原来的音高关系。
如果整曲移调仍无法容纳全部音符，可以只将超出范围的音符按八度折回支持范围，但这会改变局部旋律的音高关系；必须在谱子外注明具体小节和调整内容，不要悄悄改动。
调整八度只改变音区，不改变音符数字、长短或停顿，也不要直接删除超出音域的音符。若来源使用*、**等记号，请先根据该谱子的说明确定含义，不要一律当成高音。

程序不支持和弦、连音线或三连音。遇到看不清或无法直接表示的内容，请在谱子外说明，不要自行猜测或省略。

转换结果放在纯文本代码块中，只包含谱子，不要混入标题、歌词、页码、拍号、BPM或调整说明。
原谱若标有速度，请在代码块外单独告诉我；没有标注就说明未标速度，不要编造原曲BPM。
```

## 编译与打包

开发环境需要 .NET 8 SDK。项目目录中运行：

```powershell
dotnet run --project .\Tests\ParserTests.csproj
dotnet publish .\HarmonicaPlayer.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o .\bin\Release\publish-v0.1.5
```

每步成功后再继续。发布目录内的全部文件应一起打包。
也可使用 `Build-Release.ps1`，它先运行测试，成功后还会打开4个仅日志测试窗口，验证空闲、待保存、倒计时和播放中的关闭流程，再编译并生成 Windows ZIP；任一步失败即终止。
