# HarmonicaPlayer v0.2.0（源码候选版）

基于 v0.1.5 源码更新；当前交付未完成 .NET 编译及 Windows/游戏实测，不是已验证的 EXE 发布版。

## 本次范围

- 统一节奏模式，移除旧模式的控件、计时分支、额外停顿逻辑和设置字段。旧设置中的有效速度和快捷键自动保留。旧无节奏谱仍能按每音一拍解析，但速度需通过 BPM 调整。
- 新增最高 do `【【1】】`，按键映射为鼠标右键＋逗号。该音的游戏实际音高需要实测确认。
- 新增总拍数 `5:1.25`、`【1】:2.5`、`0:0.25`、`【【1】】:1.25`。
- 固定在窗口顶部的错误条，提供修改快捷键、重试注册按钮；普通倒计时和进度不会覆盖错误。
- 格式错误显示行、列及字符位置，提供定位与字符选中；修复后自动清除该错误。开始按钮根据曲谱和停止快捷键状态更新，并显示不可用原因；修复导入成功提示掩盖解析失败的问题。
- 增强热键冲突、目标窗口错误、失去焦点、输入失败及日志模式不发声的解释。
- 修正最短音检查漏算12ms变调准备时间的问题；播放结束取消残留进度回调，避免旧进度覆盖结束状态。
- 保留原有文本解析检查；本次不添加声音试听、导出、图形编辑及小节拍数检查。

## 运行

安装 .NET 8 SDK 后，在 Windows 项目目录运行：

```powershell
dotnet run --project .\HarmonicaPlayer.csproj
```

默认启用“仅日志测试”，不会发声，也不会向游戏发送按键。实际演奏前取消勾选，在游戏口琴界面按开始热键（默认 F6），停止默认 F8。
停止键无法注册时禁止实际演奏；开始键无法注册时仍可点击开始按钮并在倒计时内切入游戏。

## 曲谱格式

TXT 使用 UTF-8，仅放音符，不放标题、歌词或文件头。BPM 在界面设置，20～300。

| 写法 | 意义 |
|---|---|
| `1`～`7` | 中音，一拍 |
| `【1】`～`【7】` | 高一个八度 |
| `（1）` / `(1)` | 低一个八度 |
| `【【1】】` | 高两个八度 do，仅支持此音；嵌套括号中不能加时值 |
| `#1` / `【#1】` | 升半音 |
| `0` | 休止一拍 |
| `5_` / `5__` | 半拍 / 四分之一拍 |
| `5.` / `5_.` | 1.5拍 / 0.75拍 |
| `5 —` / `0 —` | 音符 / 休止增加一拍 |
| `5:1.25` | 同一个音持续1.25拍，不重新触发 |
| `0:0.25` | 休止0.25拍 |

冒号后为总拍数，必须是大于0且不超过64的整数或小数，使用英文冒号和小数点。与下一音之间请用空格隔开，例 `5:1.25 6`。
指定拍数不能再混用 `_`、`.`、`—`：`5:1.25 —` 应写为 `5:2.25`。
空格、换行和小节线不增加停顿；需停顿时明确写0。小节线只分隔，不验证是否满拍。
最短音扣除12ms变调准备和音符间隔后，实际按住时间至少40ms；过短会在开始时提示降低BPM或减小间隔，不悄悄改谱。

## 无法开始或没有声音

1. 顶部提示热键被占用：更换组合键，或关闭占用该键的其他播放器/录屏/键盘工具，再重试注册。管理员权限不能解除热键占用。
2. 曲谱错误：按提示行列修正；标题、歌词、Markdown代码围栏都不要粘贴到谱面。
3. 日志正常但不发声：检查是否勾选了“仅日志测试”；程序没有内置音频试听。
4. 倒计时后取消：请在倒计时内切到游戏口琴界面，或在游戏内按开始键。
5. 输入失败或游戏不响应：确认英文输入法、无边框/窗口模式及权限匹配；需要时以管理员运行。发送成功不等于游戏已接受输入。
6. 演奏中切换窗口会停止；除停止快捷键外，演奏时请勿操作键鼠。

## 测试与打包

```powershell
dotnet run --project .\Tests\ParserTests.csproj -c Release
dotnet run --project .\Tests\WindowsSmoke\WindowsSmokeTests.csproj -c Release
.\Build-Release.ps1
```

打包脚本在任何测试失败时停止。会生成自包含 Windows x64 EXE 发布包。
测试增加了最高音、任意拍数、非法混合符号、区域设置和错误位置用例；现有热键及停止/关闭测试保留。
发布前必须在 Windows 实际运行测试，并核对：热键冲突、更改后恢复、倒计时停止、演奏中停止、关闭窗口及右键＋逗号音高。

## 本次候选版复查修正

- 当前曲谱和热键错误分别管理，不再复制到历史操作错误中导致修正后仍残留。
- 支持定位曲谱错误；开始按钮提前反映可播放状态，日志测试不受停止热键冲突阻断。
- 打包时复制项目目录中的整个“简谱”文件夹；不存在时明确警告。本源码包不附带用户自有曲谱，不会覆盖或删除本地曲谱文件夹。
- 使用说明仅包含运行方法与常见问题，开发和编译说明保留在 README。
- 无节奏模式已经从运行逻辑移除。旧无节奏谱按每音一拍播放，依赖空白停顿的谱子需改写休止符。
- 声音试听、导出、播放列表与小节拍数校验不在此次范围内。
