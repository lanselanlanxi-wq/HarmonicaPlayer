# HarmonicaPlayer v0.2.1（更新候选版）

Windows单音简谱播放器，通过模拟键鼠在游戏内演奏。只有节奏模式；不提供本地音频试听、MIDI或播放列表。

基于main `8173cfd`（v0.2.0）。开发环境可验证核心测试和Windows目标编译；Windows窗口和游戏仍须实测，编译成功不能代替实测。

## 本次更新

- 自动读取BPM：文件头 > 文件名 > 当前有效速度。没有速度时明确提示，不根据音符猜测。
- 曲名编辑、保存TXT、另存为、新建；保存曲名、BPM和音符间隔，谱面编辑区只显示音符正文。
- 自动导入音符间隔：读取@gap（毫秒），未写时固定使用20ms，不沿用上一首。修改间隔也标记为未保存。
- 未保存修改在标题显示星号；关闭、导入、新建前可保存、放弃或取消。旧谱首次保存必须用不同文件名，修改BPM不会自动改文件名。
- 防止旧设置保存结果覆盖最新编辑或错误提示，保留顺序写入和失败重试。
- 预览、播放、保存共用时长校验，保留12ms准备时间、40ms最短按住时间和错误定位。
- 新增格式、文件保存及Windows回归测试，播放测试等待实际进度而非固定延时。

贡献来源与采纳范围见 [CONTRIBUTIONS.md](CONTRIBUTIONS.md)。本次不包含PR #1的音频功能，也没有自动合并远端PR。

## 使用

解压发布包，运行HarmonicaPlayer.exe，导入TXT并确认速度（BPM）。默认“仅日志测试”不发声、不发送键鼠。实际演奏需取消勾选，进入游戏口琴界面，按开始键（默认F6），停止默认F8。

停止键冲突时禁止实际演奏；开始键冲突时仍可点开始按钮，在3秒倒计时内切入游戏。权限应与游戏匹配，需要时以管理员运行；游戏建议无边框模式。演奏时除停止键外不要操作键鼠。

## TXT格式

旧纯音符TXT仍可导入。文件名可写“歌名 bpm100.txt”“歌名_BPM100.txt”“歌名-bpm100.txt”“歌名 bpm 100.txt”。BPM为20～300整数。

建议在软件内保存新格式：

```text
@format=HarmonicaPlayer/1
@title=节奏示例
@bpm=120
@gap=20

1 2_ 3_ 5 — |
0 6. 5_ 1 |
```

- 文件格式版本与软件版本独立。新格式要求@format和@bpm；@title可省略，导入时用文件名。界面曲名不能为空。
- 文件头与正文之间必须有空行。同名字段不能重复（不区分大小写）。未知字段提示后原样保留，但不解释其作用，例如@time不会改变节拍。
- 文件头与文件名BPM冲突时以文件头为准并提示。没有BPM时沿用界面有效速度，界面无效则使用最后有效设置。
- @gap可省略，省略时使用20ms（旧纯音符TXT也一样）。填写时必须是10～5000的整数；空值、越界、重复字段会报错。保存时自动写入当前间隔。间隔不会改变每拍总时长，但会缩短按住时间，仍受最短音校验限制。
- UTF-8，最大1MB。文件头不要粘贴进音符编辑区。
- 保存前检查曲谱、速度和间隔；先写同目录临时文件再替换目标。验证或写入失败不覆盖已有目标。
- v0.2.0及更早版本不识别新文件头；旧版兼容请单独复制正文到TXT，并在旧版设置BPM。

## 音符规则

| 写法 | 含义 |
|---|---|
| 1～7 | 中音，一拍 |
| 【1】～【7】 | 高一个八度 |
| （1）或(1) | 低一个八度 |
| 【【1】】 | 高两个八度do，仅此音 |
| #1、【#1】 | 升半音 |
| 0 | 休止一拍 |
| 5_、5__ | 半拍、四分之一拍 |
| 5.、5_. | 1.5拍、0.75拍 |
| 5 —、0 — | 增加一拍 |
| 5:1.25 | 同一个音总共持续1.25拍 |

冒号指定总拍数，大于0且不超过64，不可再混用下划线、附点或延长符。最高do的时值写在括号外，如【【1】】:1.25。空格、换行、小节线不增加停顿；小节线不执行满拍检查。扣除12ms准备和间隔后至少按住40ms，否则降低BPM或减小间隔。

完整写法见“制谱说明.txt”，AI提示词见“ai转谱模板.txt”，操作问题见“使用说明.txt”。

```powershell
dotnet run --project .\Tests\ParserTests.csproj -c Release
dotnet run --project .\Tests\WindowsSmoke\WindowsSmokeTests.csproj -c Release
powershell -NoProfile -ExecutionPolicy Bypass -File .\Build-Release.ps1
```

发布前手动检查：新旧谱导入、BPM冲突、保存再导入、取消关闭、热键冲突恢复、倒计时停止、演奏中停止、关闭窗口、最高do游戏音高。Windows自动测试仅使用日志模式，不代替游戏测试。
